# 🏥 AYBAK HOSPITAL PLATFORM

**English** | **فارسی**

## ASH NEXUS - Intelligent Hospital Operating Platform

A comprehensive, enterprise-grade hospital management system with AI-powered clinical decision support.

### Tech Stack

- **Backend Core**: NestJS (Node.js/TypeScript)
- **Backend AI**: FastAPI (Python 3.12)
- **Frontend**: Next.js 14+ (React/TypeScript)
- **Database**: PostgreSQL 16 + pgvector
- **Monorepo**: Nx workspace
- **Container**: Docker

### Quick Start

\\\ash
pnpm install
pnpm dev
\\\

### Project Structure

- **apps/** - 4 Applications
- **packages/** - 5 Shared Packages
- **infra/** - Infrastructure setup
- **docs/** - Documentation (EN/FA)
